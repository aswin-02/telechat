# TeleChat

TeleChat is a Telegram bot that integrates with OpenRouter to provide AI-powered chat responses. It uses OpenRouter's API to access various AI models, allowing users to have interactive conversations directly through Telegram. The bot maintains conversation history for each user, enabling multi-turn dialogues.

## Features

- **Telegram Integration**: Seamlessly connects to Telegram for real-time messaging.
- **OpenRouter API**: Leverages OpenRouter to access a wide range of AI models, including free models.
- **Conversation Memory**: Stores chat history per user to maintain context in ongoing conversations.
- **Custom Personality**: Configured with a custom system prompt that makes the AI respond in a blunt, sarcastic, and human-like manner.
- **Error Handling**: Gracefully handles API errors and informs users when issues occur.
- **History Management**: Automatically trims conversation history to avoid hitting context limits on free models.

## Prerequisites

- Python 3.7 or higher
- A Telegram bot token (obtained from [@BotFather](https://t.me/botfather) on Telegram)
- An OpenRouter API key (sign up at [OpenRouter](https://openrouter.ai/))

## Installation

1. Clone or download this repository to your local machine.

2. Navigate to the project directory:
   ```
   cd /path/to/telechat
   ```

3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Configuration

1. Create a `.env` file in the root directory of the project.

2. Add your environment variables to the `.env` file:
   ```
   TELEGRAM_TOKEN=your_telegram_bot_token_here
   OPENROUTER_API_KEY=your_openrouter_api_key_here
   ```

   - Replace `your_telegram_bot_token_here` with the token you received from BotFather.
   - Replace `your_openrouter_api_key_here` with your OpenRouter API key.

## Usage

1. Ensure your `.env` file is properly configured with the required tokens.

2. Run the bot:
   ```
   python bot.py
   ```

3. The bot will start polling for messages. You can now interact with it via Telegram by sending messages to your bot.

4. To stop the bot, use `Ctrl+C` in the terminal.

## How It Works

- When a user sends a message to the bot, it appends the message to their conversation history.
- The entire history (including the system prompt) is sent to OpenRouter's API.
- OpenRouter processes the request using the specified model (currently set to "openrouter/free" for the best available free model).
- The AI response is received, added to the history, and sent back to the user via Telegram.
- Conversation history is maintained per chat ID and trimmed to prevent exceeding context limits.

## Customization

### Changing the AI Personality

The bot's personality is defined by the `CUSTOM_SYSTEM_PROMPT` variable in `bot.py`. You can modify this string to change how the AI responds. For example:

```python
CUSTOM_SYSTEM_PROMPT = """
You are a helpful assistant that provides detailed explanations.
"""
```

### Selecting a Different Model

To use a different AI model, change the `model` parameter in the `client.chat.completions.create()` call. For example:

```python
model="openai/gpt-3.5-turbo"
```

Check [OpenRouter's documentation](https://openrouter.ai/docs) for available models.

### Adjusting History Length

The bot trims history to keep the last 10 messages plus the system prompt when it exceeds 20 messages. You can adjust this in the code:

```python
if len(chat_histories[chat_id]) > 20:
    chat_histories[chat_id] = [chat_histories[chat_id][0]] + chat_histories[chat_id][-10:]
```

## Troubleshooting

- **Bot not responding**: Check that your Telegram token and OpenRouter API key are correct in the `.env` file.
- **API errors**: Ensure your OpenRouter account has sufficient credits and the API key is valid.
- **Import errors**: Make sure all dependencies are installed with `pip install -r requirements.txt`.
- **Permission issues**: Ensure the bot has the necessary permissions in Telegram (BotFather can help with this).
